# Mission 2 – Terminal Operations

## 1. Task / Objective
The objective of this mission was to learn basic terminal commands and understand how to manage files and folders using the command line.

## 2. Commands Practised

| Command | Purpose |
|---|---|
| pwd | Shows the current working directory |
| ls | Lists files and folders |
| ls -l | Shows detailed file information |
| ls -a | Displays hidden files |
| cd | Changes the current directory |
| mkdir | Creates a new directory |
| touch | Creates an empty file |
| cp | Copies files |
| mv | Moves or renames files |
| cat | Displays file contents |
| echo | Writes text into a file |
| ls \| sort | Sorts the listed filenames |

## 4. Flags and Pipes
Flags change how a command works. For example, `ls -a` displays hidden files.

A pipe (`|`) passes the output of one command to another command. I practised this using `ls | sort`.
