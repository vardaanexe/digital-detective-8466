# Mission 1 – Computer Basics

## 1. IPOS Activity Table

IPOS stands for Input, Processing, Output and Storage. These are the four basic functions of a computer system.

| IPOS Stage | Description | Example |
|---|---|---|
| Input | Entering data into a computer | Typing using a keyboard |
| Processing | The CPU processes the given data | Calculating numbers |
| Output | Showing the processed result | Displaying results on a monitor |
| Storage | Saving data for future use | Saving a file on an SSD |

### Everyday Example
When I type a document on my computer:
- Input: I type text using the keyboard.
- Processing: The computer processes the text.
- Output: The text appears on the screen.
- Storage: I save the document on the computer.

## 2. Hardware Examples

Hardware refers to the physical parts of a computer that we can see and touch.

| Hardware | Function |
|---|---|
| Keyboard | Used to enter text and commands |
| Mouse | Used to point, click and select items |
| Monitor | Displays text, images and videos |
| CPU | Processes instructions and data |
| SSD | Stores files and programs |
