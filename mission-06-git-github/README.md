## 4. My Understanding

**Branch:** A separate line of development that allows changes without directly modifying the main branch.

**Pull Request:** A request to review and merge changes from one branch into another.

**Commit:** A saved snapshot of changes in Git.

**Push:** Uploading local commits to a remote GitHub repository.
